# FULL MATTER RUNNER

Top-down, ultra-violent, one-hit-kill action game in the browser.
Physics by [matter.js](https://brm.io/matter-js/), rendering on a custom Canvas2D pipeline.

## Run

ES modules need an HTTP server:

```
npm start
```

Then open the address it prints (http://127.0.0.1:8000, or the next free port when a server is already running on
that one). `npm run play` serves the last commit on port 8100 instead.

## Controls

Keyboard keys are physical positions: ZQSD on AZERTY is WASD on QWERTY. The CONTROLS page of OPTIONS lists them for
the device in use (`src/game/data/controls.js`).

| Keyboard / mouse | Gamepad | Action |
|---|---|---|
| WASD / ZQSD | Left stick | Move |
| Mouse | Right stick | Aim |
| Shift | LT | Look further ahead |
| Left click | RB (or RT) | Attack / shoot (held: an automatic keeps firing); take a guard down from behind; finish a man on the floor |
| Right click | LB | Throw: hold to aim, let go to throw (a tap throws at once); a full throw plants a blade and kills with anything else. With empty hands: pick up |
| E | X | Pick up / swap weapons, open a car's trunk, use a device (fire alarm, trapdoor, gas tap...) |
| Space | A | Vault (dive through a window, over low furniture or a car hood), climb; slide on the run |
| R | Y | Reload; retry once dead or on the results |
| Backspace | | Restart the level |
| Esc | START | Pause (also on the death screen: retry, options, quit) |

At the wheel (level 2A): W / S (Z / S) or A / D (Q / D), the left stick on a pad, steer across the road; Space / A
shoves the car on the aim's side; the mouse / right stick aims the Uzi, left click / RB fires it.

Debug (dev builds only, `src/game/data/build.js` `BUILD.release` false, or `?dev=1`): F1 sandbox panel (drop guards,
weapons, props, vehicles, blasts, water; god mode, freeze guards, slow time: a run that used it is not ranked), F2
enemy vision cones, F3 whole-level overview, F4 physics overlay (FPS, frame times), F6 lens on / off, F7 next aim cue.

## Rules

- One hit kills, for you and for them.
- Ammo is per caliber (9mm, 12 gauge, 7.62, rockets). R reloads a fresh magazine; the old one drops with what
  was left in it. Empty and nothing left? Click again to hurl the gun, John Wick style.
- Punches, thrown weapons and doors slammed into enemies knock them out. Finish them with the left click.
- Your gunshots alert guards nearby. The silenced uzi doesn't.
- Red barrels explode and set off other barrels.
- Cars: shoot the tyres flat, crack then smash the windows, puncture the tank (fuel leak), set off the alarm
  (it draws the guards), then the engine smokes, catches fire and the car blows up into a burning wreck.
- Dead bodies are ragdolls: shoot or blast them and limbs come off.
- Everything breaks: walls crack then collapse (bullets, melee, explosions), doors get ripped off their hinges,
  furniture splinters, fences and windows shatter.
- Debris is dangerous: shoot a window and the shards slice whoever stands behind it; blast debris knocks guards out.
- Clear the floor, then get back to the car.

## Tests & debug

- `npm test` runs the Node unit tests (engine, physics, map / pathfinding), no browser needed.
- `npm run qa -- --level <id>` makes a robot play a level in a headless browser (tools/qa/README.md).
- Dev builds only: `?level=lab` loads the lab (a station per feature); `?level=<id>` any level; `?killcam=off`,
  `?mark=`, `?post=0` compare switches. F1 opens the sandbox panel in any level (it lists its own keys).

## Making levels

A level is a JS module (see `src/game/data/levels/level1.js`, registered in `levels/index.js`) with three layers:

- **tiles**: one char per 32 px tile.
  - Walls: `#` interior wall, `X` brick wall, space = void (solid).
  - Floors: `.` wood, `,` checker, `+` blue tile, `:` red carpet, `;` purple carpet, `_` concrete, `"` grass, `=` asphalt, `-` road line, `~` dirt, `s` sidewalk, `*` neon dancefloor, `^` a roof one can walk on.
  - Structure: `D` door (a 2-tile run becomes double doors), `L` locked door, `G` window, `F` fence.
- **actors**: same grid.
  - `@` is the player.
  - Enemies: `p` pistol, `u` uzi, `s` silenced uzi, `h` shotgun, `r` rifle, `b` bat, `k` knife. Uppercase makes the enemy patrol.
  - Weapons on the floor: `1`-`9`, see `WEAPON_CHARS` in `src/game/data/weapons.js`.
  - Ammo boxes: `n` 9mm, `g` 12 gauge, `v` 7.62, `q` rockets.
  - Small props: `x` barrel, `c` crate, `t` trash can.
- **props**: `[type, x, y, rotationDeg]` in tile units, where a tile's centre is `n + 0.5`.
  Vehicles (`car`, `car2`, `van`) go in this list too.

Also set `exit`, and optionally `facing` overrides for guards (`"col,row": degrees`).

Optional `premises: [[col0, row0, col1, row1], ...]`: the guarded tiles. Anywhere else the guards ignore an unarmed
player until he gives himself away (without it, the whole level is hostile).

Thick blocks of `X` are the neighbouring buildings: their inside is drawn as a flat roof, which the optional
`roof: [[kind, col, row, deg], ...]` list dresses (AC units, skylights, tanks... see `src/game/data/roofs.js`).
Level 1, the tutorial and the lab are generated by `tools/build_*.py` (with `tools/levelkit.py`, which checks the layout).
